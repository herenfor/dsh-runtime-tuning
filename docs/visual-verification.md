# 审批卡与聊天表格的验收范围

当前候选：`@herenfor/dsh-tune@0.2.15-dev.5`，未发布 npm。

## 实际运行方式

将 npm tarball 安装到隔离的 DSH HOME 和 profile，启动官方 DSH web、加载插件生成的聊天客户端。在原生聊天界面进行截图、看图、计算样式与操作检查。输入由本地固定回复适配器生成；shell、edit、write 使用官方工具与真实 tools → sandbox → approval 链。独立 HTML 预览不计入验收。

| 环境 | 已验证范围 | 限制 |
| --- | --- | --- |
| Linux / WSL 内 DSH 0.2.2-rc.2 | 审批和表格的真实渲染、交互与截图 | 固定适配器；没有测试生产模型的解释质量 |
| Linux / WSL 内 DSH 0.2.2-rc.3 | 同上 | 同上 |
| dsh-wsl 0.1.12，rc.3 → rc.3 桥接 | WSL 前缀会话的快照读取、原生审批呈现与决定路由 | 使用仓库的 fakewsl 测试运输，两个 Host 都在 Linux；不冒充 Windows Electron 验收 |
| Windows Desktop | 尚未验收本次候选 | 本机真实 Desktop 已在运行，本次没有替换其 profile 或打断其中任务 |
| 局域网使用端 | 尚未验收本次候选 | 使用端暂时离线，候选仍待实机验收 |

## 检查内容

- 审批：中文深色、英文浅色，shell 默认折叠与展开、edit 替换片段、write 请求；官方允许执行真实 edit，拒绝与取消撤销卡片，取消的 write 不创建文件。
- 展开按钮上的 Enter、复制、滚动、选字及输入法 Enter 不授予权限；原生决策按钮与请求代次仍由官方组件管理。
- 正文上限 336px，标题 15px/24px，原生按钮高 36px；replacement fragment 的删除和新增行可在正文首屏查看，长内容在正文内滚动。
- 表格：宽屏实际消息列约 742px，缩小窗口获得真实 390px 消息列。覆盖 4/6 列、引用块、URL、代码和数字 129709。数字的文本 Range 保持一行。
- 默认未悬停时 overflow-x:auto；表头 600，首尾 padding 6px 9px，1px 底边。长代码表格确实溢出，可访问末列，并可用键盘横向滚动。
- 两项显示开关独立恢复原生样式/详情；切换后只有一份注入样式。浏览器检查窗口内无插件运行异常。
- 原生 never 策略在真实工具链中仍拒绝 edit，文件保持原样。未认证的元数据读取返回 401。单元测试覆盖并发歧义、取消/代次失效、凭据抑制、参数来源、未知工具 schema、纠正次数与锚点漂移。

截图、候选包、验收脚本和原始量测保留在开发机仓库外，不进入 Git 或 npm 包。每次发布前读取最新使用端验收，再更新此表；通过隔离界面测试不表示所有 DSH 功能或所有宿主组合均已验证。

## 有意保留的边界

请求目的来自模型 justification；runtime 只能约束可判定的格式，不能保证它语义真实。申请模式来自实际工具参数，不能冒充已授予或有效权限。文件参数不是 realpath，真实边界未核实会明确显示未知；脚本的完整影响、隐式 cwd 和第三方工具语义不作猜测。前置审批、关联缺失、schema 或 UI 锚点不匹配时保留原生详情。快照仅保存在 pending 生命周期内的内存中，通过已有 Connection/Typert 认证与 session 资源授权读取；不开放独立无认证 HTTP 服务，不持久化新的命令或理由副本。

桥接测试另发现官方文件改动摘要的 GET 路由在 WSL 前缀会话中返回 404；这是审批元数据 RPC 之外的路径，本次未改动 WSL 插件。原生审批的元数据与决定路由已单独核验。启动鲸鱼资源曾因聊天替身漏掉 assets 而 404，现已将对应宿主的官方资源复制到生成缓存并补齐导出，资源不进入源码包。

这是候选版本：Windows Desktop 与使用端真实会话验收完成后，再决定正式 npm 发布。
